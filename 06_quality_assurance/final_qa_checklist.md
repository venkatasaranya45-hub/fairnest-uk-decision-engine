# Final QA checklist

## Evidence
- [x] Major numerical claims trace to a named source.
- [x] Official, academic, first-party and commercial evidence are distinguished.
- [x] Transfer limitations are recorded for non-UK studies.
- [x] Dynamic platform evidence includes a review/check context.
- [x] Managerial assumptions are separated from observed data.

## Method
- [x] Secondary-research-only design is stated consistently.
- [x] No fabricated survey/interview findings are used.
- [x] Missing data are retained rather than silently converted to zero.
- [x] Reliability, validity and limitations are acknowledged.
- [x] Ethics/data minimisation are addressed.

## Commercial model
- [x] Year-1 revenue and funding gaps reconcile with the model.
- [x] Recurring provider MRR is separated from one-off exports.
- [x] Commercial prices are labelled assumptions.
- [x] Negative Year-1 cash result is not hidden.

## Artefact
- [x] Key features map to research evidence.
- [x] Fit Score remains explainable.
- [x] Paid status is excluded from ranking.
- [x] Legal context is bounded.
- [x] Evidence completeness is not described as safety probability.
- [x] Scenario tests are documented.

## Repository
- [x] Research log included.
- [x] Supervisor-feedback action log included.
- [x] Master source register included.
- [x] Literature matrix included.
- [x] Risk register included.
- [x] Rubric mapping included.
